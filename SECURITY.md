# Security Policy

## Supported versions

Security fixes are provided for the latest `0.1.x` release and the `main`
branch. Older development snapshots are not supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting form](https://github.com/MilanoTechnicalGroupInc/isaac-sim-gaussian-lod/security/advisories/new)
and include:

- the affected version or commit;
- reproduction steps or a proof of concept;
- the expected impact;
- any suggested mitigation.

The maintainer will acknowledge a report within three business days and will
coordinate remediation and disclosure through the private advisory.

Never include active credentials, proprietary datasets, or unnecessary
personal information in a report.
